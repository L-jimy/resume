01 · BEFORE

原来卡在哪里？

各部门零散提出自动化需求，应用陆续堆叠形成，但业务、技术、数据三条线仍是「孤岛 + 人工」。

✕ 改造前的 5 大痛点

自动化应用靠需求堆叠，缺乏统一设计与专人维护，技术债重，故障与数据漂移风险持续上升
各部门各自为战：客服、采供、跨境、新零售、运营、财务，需求分散、无法复用
业务变化 → 应用跟不上 → 人工补位 → 新的需求 → 恶性循环，应用与业务逐渐脱节
智能程度低：自动化能跑但不会判断，遇到异常只能靠人发现、人工兜底
缺乏 AI 智能助手，员工找数据、问系统、查知识库，依赖同事口口相传

✓ 改造目标

存量应用从「堆叠」转为「可维护资产」，巡检 + 监控 + Runbook + 自愈重试
各部门需求按业务域归位，形成可复用的模板化组件与交付标准
业务规则变化 → 应用快速迭代，上线后有复盘，持续跟上业务节奏
AI 嵌入关键节点：意图判断、质检评分、舆情预警、失败兜底，自动化 → 智能应用
建设企业级多轮对话智能助手，员工自然语言即可查数据、问系统、查知识库

一句话说我在做什么

就是把客服、供应链、跨境运营、数据监控这些重复、碎、容易错的事情， 用 RPA + AI 搭成能自己跑的小系统，让人不用再靠 "记住某件事要在某个时间点手动做" 活着。

02 · 六大类方案

每类都做过不止一遍

每个业务域对应一类共性问题：先看它原本卡在哪，再看我用什么方式把它做成可复用的方案。

PHASE 01

客服智能化

5 大电商平台

覆盖淘宝 / 京东 / 抖音 / 拼多多 / 店小秘多平台，把传统客服从「凭经验」升级为「数据驱动 + AI 辅助」。

解决的问题

聊天记录散落在多个平台、质检靠人工抽听、退货原因说不清，管理者只能凭感觉判断服务质量。

方案思路

会话自动归档 + AI 多维质检 + 原因聚类分析，把「看不完的会话」变成可检索、可评分、可归因的结构化数据。

多平台聊天记录自动抓取

跨平台（纯机/京东/抖店/拼多多/淘宝/店小秘/企微群）聊天记录自动归档，支持按关键词、日期、客服快速检索。

AI 售前售后技术质检

多机型（MT56i / Z6 / W1 / FT 等）售前售后对话质检，检测话术合规、产品知识性、服务态度三大维度。

退货原因 / 咨询原因智能分析

按机型、按平台、按时间维度聚合退货原因与咨询内容，识别 Top 问题点，驱动产品优化。

舆情与满意度监控

小红书舆情抓取、多平台差评 / 客诉实时预警、满意度自动抓取汇总，异常自动通知。

输入多平台会话、订单、评价数据 输出质检报告 · 原因分析 · 舆情预警 · 满意度看板
PHASE 02

供应链自动化

6 大系统集成

打通聚水潭 / 领星 / 京东 SAP / WMS / 自研系统，库存、出入库、物流、对账全链路自动化运行。

解决的问题

库存分散在多套系统，对账靠人工拉表比对，异常订单靠人盯，链路一长就容易错漏、扯皮。

方案思路

以单据为主线做系统间自动流转：规则触发变更、账单自动对账、异常自动拦截，人工只在规则变更时介入。

WMS 逻辑仓自动变更

规则触发 WMS 逻辑仓变更，消除人工操作，减少 80% 仓配异常。

京东 SAP 自动对账 + 物流下单

京东 SAP 账单自动拉取与对账、京东物流自动下单（含达人渠道），消除重复人工。

序列号 / 料号批量查询

按料号查出入库数量、按序列号查明细、查询 BOM 结构、查询长交期物料，供应链快速响应。

分销自动拦截 + 供应链库存多源监控

异常订单自动拦截快递，实时监控聚水潭 / 领星 / 大库三源库存，滞销库存自动识别。

输入WMS / 聚水潭 / 领星 / 京东 SAP / ERP 输出自动对账 · 自动拦截 · 库存视图 · 异常告警
PHASE 03

跨境电商运营

4 大跨境平台

TEMU / 亚马逊 / TikTok Shop / 领星，全球站点数据采集与运营操作自动化。

解决的问题

各站点后台彼此独立，导出、回填、监控都要人工逐个登录操作，多店多站点时工作量成倍放大。

方案思路

统一入口 + 定时任务：数据自动采集汇总、单号与库存自动回填、LISTING 与库存异常自动提醒。

TEMU / 亚马逊 数据采集

TEMU 销售数据自动导出、亚马逊广告周报自动下载、亚马逊关怀邮件自动发送。

TikTok Shop 物流与内容

TikTok 物流单号回填、消息提醒监控、库存查询、视频下载，跨境运营全链路支持。

领星 LISTING 监控 + FBT 库存提醒

LISTING 健康状态（权限 / 合规 / 异常）自动巡检，FBT 库存低于阈值自动提醒。

输入TEMU / Amazon / TikTok Shop / 领星 输出销售报表 · 广告数据 · LISTING 监控 · 库存提醒
PHASE 04

数据采集与监控

采集 · 清洗 · 预警

企业级数据采集基础设施，多平台数据自动拉取、清洗、汇总，配合定时调度实现异常实时预警。

解决的问题

数据分散在网页、API、Excel 里，人工复制粘贴既慢又易错；出了问题往往是事后才发现。

方案思路

把「采集 - 清洗 - 汇总 - 校验 - 告警」固化为标准管道，同一套模板换数据源即可复用。

产线 + 仓库 实时监控

产线数据监控、准新机仓未发货提醒、WMS 回传异常自动告警、仓库报表自动监控。

多平台数据采集

快捞数据抓取、多平台综合分数抓取、淘宝发票抓取、退款数据下载、抖音数据抓取。

销售报表自动导出

销售分析统计（定时）、出货数据统计、月度成交金额统计、领星 MSKU 数据导出。

输入多平台 API / 网页 / Excel 输出报表 · 看板 · 企微 / 邮件告警
PHASE 05

AI 智能体

多轮对话 Agent · 9 系统接入

主导搭建的企业级多轮对话智能体——汉印小智。集成意图路由、槽位抽取、RAG 知识库检索、失败兜底策略，让员工自然语言就能查数据、问系统。

解决的问题

员工查库存、问订单、找流程要跨多个系统或问同事，响应慢、口径不一，知识沉淀在个人身上。

方案思路

用一个对话入口承接常见查询：先识别意图与参数，再调对应系统接口，查不到自动转知识库，并做权限校验与失败兜底。

13 种功能意图自动识别

库存查询 / WMS 变更 / 京东下单 / 维修查询 / 出入库 / 原材入库 / 京东库存 / 内购 / 长交期物料 / 云计费 / BOM 查询 等。

9 大内部系统 API 直连

库存、出入库、WMS、京东订单、维修、原材、内购、长交期、云计费，每个接口含重试与超时保护。

RAG 检索 + 失败兜底

API 异常自动走知识库检索路径，重排序 + top_k 调优提升召回准确率；硬约束提示词控制幻觉。

输入员工自然语言查询 输出结构化业务回答 / 引导提问
PHASE 06

运营 / 财务 / 管理支持

高频重复场景

覆盖发票处理、报表下载、采购标签打印、自动巡店、认证管理等非业务核心但高频重复的操作场景。

解决的问题

不产生业务价值却每天都要做：下载报表、回传发票、打标签、巡店，占掉大量碎片时间又容易漏。

方案思路

按场景做「一键化 + 定时化」的小工具，统一异常通知，把固定动作全部交给系统按点执行。

运营支持

发票信息抓取 / 发票冲红 / 发票回传、退款数据自动下载、消费券核销、企微群文章抓取。

财务支持

TK 报表自动下载、抖音发票自动回传、亚马逊报表下载、分销对账处理。

管理 / 采购 / 认证

采购标签批量打印（聚水潭）、认证管理证书上传、汉印云计费系统停机保号、自动巡店。

输入运营 / 财务 / 管理部门需求 输出自动化批量操作 · 周期性报表

🤖 汉印小智机器人

企业内部多轮对话智能助手 · 覆盖供应链 9 大查询场景 · Dify Workflow + RAG + 9 System APIs

📋 5 步处理流程（点击联动）

1
用户输入

接收自然语言查询，进入多轮对话上下文

会话变量维持多轮对话。例：先问 "SN 有库存吗"，再追 "最近入库时间呢"，自动关联。
2
槽位抽取 + 功能词路由

Python 正则抽取编号 / 手机号，匹配 13 种功能意图

路由规则覆盖：库存查询、WMS 变更、京东下单、维修、出入库、原材入库、京东库存、内购、长交期物料、云计费、BOM 等。
3
参数完整性校验

必要参数齐全？缺失则引导补充

用户只说 "查库存" 没给料号 → 回复 "请提供料号或规格名称"，避免无效 API 调用。
4
意图分派 → API / 引导

按功能类型调用对应内部系统，含权限校验

HTTP Request 节点对接 9 大系统：库存、出入库、WMS、京东订单、维修、原材、内购、长交期、云计费。每个接口含重试与超时保护。
5
RAG 知识库兜底

检测失败关键词 → 自动走知识库检索

硬约束提示词控制幻觉：检测 "暂无权限/无法查询/未找到" → 自动切换 RAG 检索路径，不会返回空结果。

05 · 前后对比

传统模式 vs 系统性交付

零散人工 vs 模块化系统，当业务规模上来，系统性交付的优势会越来越显著。

维度 ✕ 改造前 ✓ 改造后
需求响应零散接需求，一人一事，重复做同类工具先归域再设计，同类场景复用同一套模板
系统维护没人专职维护，故障靠人工救火巡检 + 监控 + Runbook + 自愈重试，异常可发现、可恢复
AI 能力只能执行固定流程，不会判断AI 嵌入关键节点：意图识别、质检评分、失败兜底
系统对接逐个系统点对点，接口口径各异统一接口规范与重试超时保护，多系统稳定串联
异常处理出错后靠人发现、靠人补救关键节点自动校验 + 企微 / 邮件实时告警
知识沉淀经验留在个人，新人重新摸索汉印小智多轮对话 Agent，自然语言即可查数据、问流程
